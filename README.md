# 출장비 정리기

## 쓰기 전에

- **넣은 파일은 브라우저를 떠나지 않습니다.** F12 → Network 탭을 열어 두고 파일을 넣어 보세요. 파일을 넣은 뒤로는 새 요청이 하나도 생기지 않습니다(처음 열 때 화면 파일과 `rules/` 처방을 받는 것뿐).
- **이 정리기가 못 하는 것:** 박수 `20` 같은 튄 박수와 `-97,700` 같은 음수 금액은 고치지도 표시하지도 않고, 처방에 없는 부서 이름(제조팀 · IT개발팀 · Dev팀 · 회계재무팀)은 그대로 둡니다.
- **처방을 바꾸려면 코드가 아니라 `rules/` 의 파일을 고칩니다** (예: `rules/출장비정산.json`).

---

## 무엇을 하나

출장비 정산 엑셀을 화면에 끌어다 놓으면, `rules/` 의 처방대로 정리해서 두 파일을 내려줍니다.

- **정리본** (`<파일 이름>_정리본.xlsx`) — 고친 값과, 고치지 않은 까닭을 적은 `_표시` 칸
- **바꾼 기록** (`<파일 이름>_바꾼기록.xlsx`) — 바꾼 칸 한 줄씩(원래 값 · 바뀐 값 · 이유), 표시한 줄, 요약

모르는 값은 지어내지 않습니다. 빈칸, 너무 큰 금액, 있을 수 없는 날짜는 고치지 않고 `_표시` 칸에 까닭을 적습니다.

## 쓰는 법

1. 엑셀 파일(.xlsx · .csv)을 끌어다 놓거나 눌러서 고릅니다.
2. 줄 수 · 칸 수와, 이 파일에 맞는 처방과 이유를 확인합니다. 처방은 파일 이름으로 찾습니다(`출장비정산.xlsx` → `rules/출장비정산.json`). 맞는 처방이 없으면 처방 파일(.json)을 직접 고를 수 있습니다.
3. **규칙대로 정리**를 누릅니다. 행 전후 · 지운 행 · 고친 값 · 표시한 행 · «두 번 돌려도 같은 결과»를 보여 줍니다.
4. 정리본과 바꾼 기록을 내려받습니다.
5. (선택) **정답과 대조** — 정답 파일을 내 컴퓨터에서 고르면 일치 · 어긋난 칸을 보여 줍니다. 정답 파일은 이 사이트에 없습니다.

## 처방 고치기

처방 파일은 칸마다 무엇을 할지 적은 JSON 입니다. 각 처방의 `why` 에는 정한 사람의 이유를 그대로 적습니다.

| 항목 | 하는 일 |
|---|---|
| `trim` | 앞뒤 공백을 지운다 |
| `map` | 적힌 값을 바꾼다 (`"영업부": "영업팀"`) |
| `strip_units` | 글자를 뗀다 (`["원"]`) |
| `number` | 숫자로 바꾼다 (쉼표도 뗀다) |
| `date` · `date_rules` | 날짜를 YYYY-MM-DD 로. 있을 수 없는 날짜는 «확인 필요»로 표시 |
| `missing: "flag"` | 빈칸은 채우지 않고 표시 |
| `range` | 범위를 벗어나면 남기고 표시 |
| `cross_checks` | 칸 사이 조건에 맞으면 표시 (예: 박수 0 인데 숙박비 > 0) |
| `duplicates` | 모양을 맞춘 뒤 완전히 같은 줄은 하나만 남긴다 |

새 처방 파일을 만들면 `rules/index.json` 의 `files` 에 이름(.json 뺀 것)을 더합니다. 화면은 처음 열릴 때 이 목록의 처방을 모두 미리 받아 두므로, 어떤 파일을 넣었는지(파일 이름)도 서버로 가지 않습니다.

## 내 컴퓨터에서 열기

```
python -m http.server 8000 --bind 127.0.0.1
```

이 폴더에서 실행한 뒤 http://localhost:8000 을 엽니다. `index.html` 을 더블클릭해서 열어도 되지만, 그때는 처방을 자동으로 못 읽으므로 처방 파일을 직접 골라야 합니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` · `style.css` · `app.js` | 화면 |
| `clean.js` | 정리 엔진 — 처방을 읽어 그대로 할 뿐, 처방 내용은 없다 |
| `lib/` | SheetJS (엑셀 읽기·쓰기) — 다른 사이트에서 불러오지 않는다 |
| `rules/` | 처방 파일 |
| `data/` | 시험용 지어낸 엑셀 (개인정보 없음) |
